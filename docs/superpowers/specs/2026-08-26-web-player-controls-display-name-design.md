# PartyLAN 网页播放器式控件与大厅显示名设计

**日期：** 2026-08-26  
**状态：** 已确认  
**范围：** 网页端 Screego 原生 React UI 与显示名回退逻辑；不修改登录身份、房间 ID、媒体协议或桌面客户端

## 目标

- 桌面房间页的左右完整面板和底部全屏按钮采用视频播放器式自动显隐。
- 大厅不再显示“你好，用户”，改为“用户名显示”与可编辑显示名输入框。
- 设置弹窗移除用户名与帧率字段，只保留编码器和显示模式。
- 登录账号 ID 继续用于认证与创建自己的固定房间，显示名只用于成员列表。

## 控件显隐

- 页面初次进入时控件短暂可见。
- 桌面端任意鼠标移动会同时显示左侧成员面板、右侧共享面板和底部全屏按钮。
- 停止移动 2.2 秒后，这三组控件使用 `opacity` 与 `transform` 隐藏，不改变视频布局尺寸。
- 指针位于控件内、设置弹窗打开或键盘焦点位于控件中时保持显示。
- 隐藏控件不接收指针事件；`prefers-reduced-motion` 下取消位移动画。
- 连接数据面板和房间标题沿用现有行为，不纳入本次功能删改。
- 移动端继续常驻底部成员、全屏和共享入口，通过点击展开单个底部抽屉。

## 显示名

- 大厅头部显示明确标签“用户名显示：”和一个最大 64 字符的输入框。
- 输入值保存在现有 `screegoSettings.name` 本地设置中，后续创建或加入房间时自动携带。
- 首次没有本地显示名时，已登录用户以账号 ID 作为输入框默认值；访客允许自行输入。
- 创建或加入前对显示名去除首尾空白；空值回退到已登录账号 ID，访客空值继续由服务端生成随机显示名。
- 服务端优先使用请求中的非空显示名，仅在显示名为空时回退到认证账号，保证编辑结果在进入房间后立即生效。
- 显示名不参与权限判断、登录会话或房间 ID 生成。

## 设置弹窗

- 删除用户名输入框、帧率输入框和即时重命名回调。
- 保留首选编码器、显示模式、取消和保存。
- `Settings.name` 与 `Settings.framerate` 数据字段继续保留：名称由大厅维护，帧率由共享面板维护，避免破坏已有本地设置和媒体采集逻辑。

## 验证

- 源码测试覆盖鼠标移动显隐属性、2.2 秒延迟、移动端常驻入口、大厅显示名输入和精简设置弹窗。
- Go 测试覆盖认证用户显式显示名优先及空显示名回退账号 ID。
- 桌面浏览器验证移动后同时出现、静止后同时隐藏、悬停时保持。
- 375px 移动视口验证底部入口和抽屉不受影响，大厅输入框不产生横向滚动。
- 在干净 Screego revision 上重放全部补丁并通过生产构建和运行时回归。

## 回滚

撤销本次新增补丁并恢复上一版不可变网页镜像即可；本地设置格式和服务端持久数据均不需要迁移。
