# partylan 网页原始应用图标恢复设计

**日期：** 2026-08-27
**状态：** 已确认
**范围：** 网页端品牌图片资源与入口页面引用；不修改桌面客户端图标、房间功能或媒体逻辑

## 目标

- 网页恢复使用仓库初始提交中的 `build/appicon.png` 原始霓虹手柄图标。
- 首页、浏览器页签、Apple 触屏图标和分享预览使用同一份原图，消除现有 SVG 标志与替代手柄图不一致的问题。
- 原图不重新绘制、不改色、不裁切；页面仅按现有响应式尺寸等比缩放。

## 实现

- 将 `/appicon.png` 作为网页品牌图片主地址，由 Nginx 从部署目录提供 PNG；旧图标地址继续兼容，但返回同一份原图。
- Screego 原生 React 大厅将首页图片源从 `./logo.svg` 改为 `./appicon.png`。
- HTML 的 favicon、Apple 触屏图标和 Open Graph 图片统一改为 `/appicon.png`。
- 品牌图片响应增加禁止缓存头，确保替换后现有设备不会继续显示旧图。
- 部署时把 `build/appicon.png` 原样复制到服务器维护目录与活动静态资源目录；两端 SHA-256 必须与仓库原文件一致。

## 验证与回滚

- 自动测试校验入口源码和 Nginx 均只引用 `/appicon.png`，并校验原图文件存在及固定哈希。
- 在干净 Screego revision 上重放全部补丁，通过 UI 测试与生产构建。
- 桌面和移动视口分别确认首页原图完整可见，浏览器请求返回 `image/png` 且无旧缓存。
- 回滚时恢复上一版不可变镜像、原静态图片和 Nginx 配置备份。
