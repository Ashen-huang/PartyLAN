# PartyLAN 网页端左右悬停面板设计

**日期：** 2026-08-25  
**状态：** 已确认  
**范围：** 仅网页端 Screego 原生 React UI，不修改 Wails 桌面客户端或媒体协议

## 目标

- 网页端颜色主题与 PartyLAN 客户端保持一致。
- 桌面端成员列表放在左侧，共享面板放在右侧。
- 左右面板仅在鼠标进入对应侧边区域、键盘焦点进入或用户主动固定时显示。
- 全屏按钮脱离侧栏，固定在页面底部正中间。
- 设置和退出按钮放在共享面板底部。
- 移动端保留收纳式交互，但入口和展开面板放在页面底部。

## 桌面布局

网页房间页面提供三个相互独立的工具区域：

1. 左侧成员区：侧边默认只显示成员图标手柄；悬停或聚焦左侧区域时，直接展开完整成员列表。
2. 右侧共享区：侧边默认只显示共享图标手柄；悬停或聚焦右侧区域时，直接展开完整共享设置和共享操作。
3. 底部全屏区：页面底部正中固定显示全屏/退出全屏图标按钮，不随左右面板隐藏。

成员列表和共享面板使用 `position: fixed` 覆盖在观看区域上方，不进入视频布局流，避免改变画面尺寸或比例。左右区域互不依赖，鼠标离开一侧只收起该侧内容。

共享面板底部使用一条独立操作区放置设置和退出按钮。开始/停止共享仍位于共享内容区内，并继续调用现有 `share()` / `stopShare()`。

## 移动端布局

在窄屏或不支持 hover 的设备上，左右侧边悬停交互切换为底部收纳栏：

- 底部栏提供成员、全屏和共享三个图标入口。
- 点击成员或共享入口后，从底部展开对应抽屉；再次点击、点击关闭按钮或按 Escape 后收起。
- 抽屉宽度受视口约束，高度限制在可视区域内并允许内部滚动。
- 设置和退出仍位于共享抽屉底部。
- 底部栏与抽屉不改变观看区的布局尺寸。

## 主题与可访问性

面板复用客户端当前视觉令牌：浅青色背景、青蓝色边框、青绿色交互强调、深色正文和红色退出/停止状态。保持 8px 以内的控件圆角，并为按钮提供明确的 hover、focus-visible、disabled 状态。

所有图标按钮保留可读的 `aria-label` 和 Tooltip。桌面悬停区域同时支持 `:focus-within`；移动端不依赖 hover。尊重 `prefers-reduced-motion`，关闭抽屉过渡但不影响显示状态。

## 状态与边界

- 共享、成员、全屏、设置和退出继续使用现有 React 状态与回调。
- 不修改 SFU/P2P、Presence、共享租约、音频策略、自适应画质或媒体采集逻辑。
- 不修改 `frontend/src` 桌面客户端。
- `inject.js` 继续只承担兼容、诊断和主题增强，不创建第二套原生工具栏。
- 取消系统捕获选择或共享失败后，右侧面板保持可重试状态。

## 测试与验收

- 原生 UI 源码测试验证左右独立面板、底部全屏按钮、共享底部设置/退出入口和移动端底部收纳样式。
- 在干净的锁定 Screego revision 上应用全部补丁，确保 patch hunk 有效。
- 运行原生 UI Node 测试、TypeScript 生产构建和现有网页注入回归测试。
- 用桌面和移动视口检查：面板可见性、按钮位置、文本溢出、视频布局不变和控件无重叠。

## 回滚

改动只存在于 `server/screego/patches/0006-partylan-native-web-ui.patch`。回滚该补丁和对应不可变网页镜像即可恢复当前右侧工具栏布局，不需要重启或迁移媒体服务。
